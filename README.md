# amo2

Google Apps Script для работы с таблицей:
`https://docs.google.com/spreadsheets/d/1_G3iskoNiluovIPPW8X4QzK0GnT_F9TQLbdQjHJBATQ`

## Что делает скрипт

Функция `buildRefusalReasonSummary()`:
- читает столбец **E** (поле "Этап сделка") на листе-источнике;
- читает столбец **F** (поле "Бюджет") для расчета недополученной прибыли;
- отбирает только строки, где есть этап `закрыто и не реализовано`
  (также поддерживается вариант `закрыто и нереализовано`);
- извлекает причину отказа из скобок, например `(Не можем реализовать)`;
- считает количество сделок по каждой причине;
- считает `процент от общего числа сделок`, где общее число — это количество
  непустых `Id` в столбце **A**;
- суммирует бюджет по каждой причине в поле `недополученная прибыль`;
- если причина не указана, использует значение `причина не указана`;
- записывает результат на лист `Сводка причин отказа` в формате:
  - `причина отказа`
  - `количество`
  - `процент от общего числа сделок`
- также создает отдельный лист `Сводка причин отказа и прибыли` в формате:
  - `причина отказа`
  - `количество`
  - `недополученная прибыль`
  - `процент от общего числа сделок`
- создает лист `Сводка причин по месяцам`, где для **каждой причины отказа**
  есть отдельная таблица по месяцам (октябрь-май и далее при появлении новых данных):
  - `месяц`
  - `количество`
  - `процент от общего числа сделок` (в рамках конкретного месяца)
  - `недополученная прибыль`
- на листе `Сводка причин по месяцам` также строятся 2 больших графика:
  1. по количеству сделок,
  2. по недополученной прибыли,
  где каждая причина отказа выводится отдельной серией со своим цветом и легендой.
- создает лист `Сводка успешных сделок` по статусам из столбца **E**:
  - `успешно реализовано`
  - `отправка`
  - `закрытие договора`
  и считает для каждого статуса:
  - `количество сделок`
  - `общая сумма бюджета` (столбец **F**)
  - `процент от общего числа сделок` (по непустым `Id` из столбца **A**)
  - отдельной строкой считает общую конверсию в успешную сделку
    (сумма трёх статусов / общее число сделок)
- создает 2 листа по компаниям для успешных сделок:
  - `Успешные сделки по компаниям (сумма)` — суммы по бюджету,
  - `Успешные сделки по компаниям (количество)` — количество сделок.
  В обоих листах:
  - строки — названия компаний,
  - столбцы — `успешно реализовано`, `отправка`, `закрытие договора`, `итого`.
  Название компании берется из столбца **C**; если C пустой, извлекается из
  столбца **B** (после номера сделки в начале строки).

Лист-источник определяется автоматически:
1. если в `Code.gs` задан `SOURCE_SHEET_NAME`, берется он;
2. иначе ищется лист, где заголовок `E1` содержит `этап`;
3. если не найдено, берется первый лист, кроме листа сводки.

## Как запустить

1. Открыть проект Apps Script.
2. Вставить содержимое `Code.gs`.
3. Запустить функцию `buildRefusalReasonSummary`.

## Автообновление при новых данных

Чтобы все листы обновлялись автоматически при изменениях в исходной таблице:

1. В проекте уже есть `onEdit(e)` — он обновляет отчеты при ручном редактировании.
2. Для повышенной надежности (изменения не только через ручное редактирование)
   один раз запусти функцию `installAutoRefreshTriggers()`.
3. Подтверди доступы.

После `installAutoRefreshTriggers()` скрипт создаст 3 триггера:
- `onEdit` — обновление после редактирования таблицы;
- `onChange` — обновление при изменениях структуры/импортах;
- `everyMinutes(5)` — резервное обновление каждые 5 минут.

Если нужно отключить автообновление, запусти `removeAutoRefreshTriggers()`.

Если автообновление перестало срабатывать после изменений структуры/данных:
1. запусти `removeAutoRefreshTriggers()`;
2. затем снова `installAutoRefreshTriggers()`.

## Кнопка в интерфейсе таблицы

В таблицу добавлено меню `Отчеты CRM` (появляется после открытия таблицы или
после перезагрузки вкладки). Через него можно запускать скрипт вручную:

- `Отчеты CRM` → `Обновить все отчеты`

Также в этом меню есть пункты:
- `Включить автообновление`
- `Отключить автообновление`

Дополнительно создается заметный лист `⚡ Обновление отчетов` с визуальной
кнопкой-чекбоксом:

- кнопка подписана как `обновить данные`;
- нажми чекбокс в ячейке `B4` — запустится полное обновление всех отчетов.

Если лист с кнопкой не появился, запусти функцию `setupRefreshButton()`.
