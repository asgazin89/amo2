# amo2

Google Apps Script для работы с таблицей:
`https://docs.google.com/spreadsheets/d/1_G3iskoNiluovIPPW8X4QzK0GnT_F9TQLbdQjHJBATQ`

## Что делает скрипт

Функция `buildRefusalReasonSummary()`:
- читает столбец **E** (поле "Этап сделка") на листе-источнике;
- читает столбец **F** (поле "Бюджет") для расчета недополученной прибыли;
- отбирает только строки, где есть этап `закрыто и не реализовано`
  (также поддерживается вариант `закрыто и нереализовано`);
- извлекает причину отказа из скобок, например `(Не можем реализовать)`;
- считает количество сделок по каждой причине;
- суммирует бюджет по каждой причине в поле `недополученная прибыль`;
- если причина не указана, использует значение `причина не указана`;
- записывает результат на лист `Сводка причин отказа` в формате:
  - `причина отказа`
  - `количество`
- также создает отдельный лист `Сводка причин отказа и прибыли` в формате:
  - `причина отказа`
  - `количество`
  - `недополученная прибыль`

Лист-источник определяется автоматически:
1. если в `Code.gs` задан `SOURCE_SHEET_NAME`, берется он;
2. иначе ищется лист, где заголовок `E1` содержит `этап`;
3. если не найдено, берется первый лист, кроме листа сводки.

## Как запустить

1. Открыть проект Apps Script.
2. Вставить содержимое `Code.gs`.
3. Запустить функцию `buildRefusalReasonSummary`.
