# amo2

Google Apps Script для таблицы:
`https://docs.google.com/spreadsheets/d/19cqiVBuTDFdCUAyAw_1SkuLPEX5kzTOkO6NWDR_xHP8`

## Что делает скрипт

Функция `buildSingleDealCompaniesReport()`:
- использует поле **`Название сделки`** для извлечения названия компании;
- нормализует название компании (убирает код сделки и вариации кавычек);
- считает, сколько заказов у каждой компании;
- оставляет только компании, которые сделали **ровно 1 заказ**;
- все компании с 2+ заказами полностью исключаются из результата;
- формирует отдельный лист **`Компании с одной сделкой`**;
- выводит поля:
  - `Название сделки`
  - `Бюджет`
  - `Этап сделки`
  - `Дата открытия`
  - `Дата закрытия`
  - все доступные контактные поля (email/телефоны/telegram и т.д.) отдельными столбцами.

## Как запустить

1. Открыть Apps Script, связанный с таблицей.
2. Вставить код из `Code.gs`.
3. Запустить `buildSingleDealCompaniesReport()`.
